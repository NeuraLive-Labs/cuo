# Ponytail integration

Upstream: https://github.com/dietrichgebert/ponytail (MIT).

## CUO behavior

- Detects install markers (`~/.config/ponytail`, skills/plugins, AGENTS.md markers).
- May import local band artifacts under `~/.config/ponytail/band/` as **Imported**.
- Does **not** copy or redistribute Ponytail components.
- Does **not** assume a public live metrics API beyond documented local files / commands.

## Role split

Ponytail improves *how* the agent writes code. CUO measures and coordinates.
